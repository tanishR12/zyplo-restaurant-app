# Zyplo Restaurant Android app

Public download for the restaurant orders & management app (`https://zyplo.in/restaurant-login`).

## Download APK

Latest build: **[Download APK](https://github.com/tanishR12/zyplo-restaurant-app/releases/latest)**

Install `ZyploRestaurant-debug.apk`, allow notifications, GPS, camera, overlay, and unrestricted battery, then log in.

Package name: `in.zyplo.restaurant`
